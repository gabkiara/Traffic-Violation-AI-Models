# Traffic-Violation-AI-Models

Created AI Models for Smart Highway Surveillance: Real-Time Traffic Violation Detection Using YOLOv8 and IP Camera, a Capstone project. Iba Zambales local highway road, in the Philippines.

Annotated with Roboflow, trained with a local machine, with local vehicles in mind. Models include vehicle detection, vehicle color detection, license plate detection, tricycle body number detection, and traffic violation detection using YOLOv8 algorithm.
